FDE Mindset Principles

1. No Hallucination Without Citation
ในงาน Enterprise AI คำตอบที่ไม่มีหลักฐานอ้างอิงชัดเจนถือว่าใช้งานไม่ได้จริง การมี Citation ที่ชี้หน้าและท่อนข้อความตรงเป๊ะสำคัญกว่าความสวยงามของข้อความตอบ
2. Operational Actions > Analytics
FDE ไม่ได้สร้างแดชบอร์ดไว้นั่งดูตัวเลขเฉยๆ แต่สร้างเครื่องมือเพื่อให้เจ้าหน้าที่หน้างาน (Reviewer) กด Take Action (เช่น อนุมัติ, ตีกลับ, ปรับสถานะ) ได้ทันที
3. TDD on Ingestion & Edge Cases
ข้อมูลลูกค้าไม่เคยสมบูรณ์แบบเสมอ เราต้องใช้ Test-Driven Development ในการจำลองข้อมูลที่ขาดหายหรือผิดเพี้ยนไว้ล่วงหน้า

Context: Vendor Compliance

การรักษาคำศัพท์เหล่านี้อย่างเคร่งครัดช่วยให้ทั้ง Software, Database Schema, Code Classes, และ LLM Prompt เข้าใจตรงกัน

Canonical Term Definition Avoid Synonyms
Dossier ชุดรวมของสัญญา ใบรับรอง และข้อมูลบริบทของคู่ค้าที่ส่งเข้ามาพิจารณาในหนึ่งรอบ _Avoid_: Upload, Ticket, Request, File, Submission
Artifact เอกสารแต่ละฉบับที่อยู่ใน Dossier เช่น สัญญา SLA หรือใบรับรอง ISO _Avoid_: File, Attachment, PDF
Policy เอกสารนโยบายและระเบียบบริษัทที่กำหนดเกณฑ์มาตรฐานที่คู่ค้าต้องปฏิบัติตาม _Avoid_: Guideline, Rulebook, Standard
Criterion ข้อกำหนดหรือเงื่อนไขเดี่ยวที่ถูกสกัดมาจาก Policy เพื่อนำมาตรวจกับ Artifact _Avoid_: Rule, Condition, Check, Prompt
Finding ผลการประเมินต่อหนึ่ง Criterion (Pass, Flagged, Inconclusive) พร้อมหลักฐาน Citation _Avoid_: Output, Result, Answer, Score, Verdict
Citation จุดอ้างอิงชัดเจน (เลขหน้า, วรรค, ข้อความ) ภายใน Artifact ที่เป็นหลักฐานของ Finding _Avoid_: Source, Link, Excerpt, Reference
Case หน่วยงานที่เปิดขึ้นเมื่อมี Findings ที่ต้องให้เจ้าหน้าที่เข้ามาตรวจสอบ _Avoid_: Task, Job, Ticket, Issue
Reviewer เจ้าหน้าที่ผู้เชี่ยวชาญด้าน Compliance ผู้มีสิทธิ์วินิจฉัยและปิด Case _Avoid_: User, Admin, Operator, Auditor
Determination คำวินิจฉัยสุดท้ายของ Reviewer (เช่น Approved, Rejected, Escalated, Request Info) _Avoid_: Verdict, Resolution, Status, Action
