# Forward Deployed Engineer (FDE) Learning Project: DocuAudit

A hands-on, enterprise-grade project for mastering Forward Deployed Engineering skills:
- **Domain Modeling & Ubiquitous Language**: Clean separation between business domain and technical artifacts.
- **Document & Data Ingestion**: Handling messy real-world contracts, PDFs, and ISO certifications.
- **Hybrid RAG & Exact Citation Engine**: Dense + Sparse BM25 retrieval with strict source provenance (no hallucination without citation).
- **Compliance Rule Engine**: Schema-enforced evaluation (Pass, Flagged, Inconclusive).
- **Agentic Triage & State Machine**: Routing cases to human operators via canonical 5-role triage vocabulary.
- **Operator Action Workspace**: Operational interface for review, audit trail, and determination.
